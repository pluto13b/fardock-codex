# FarDock public development status

This is the first public source snapshot. Private deployment logs, internal handoff records, addresses, and prior development history are intentionally not included.

The repository contains a Windows Companion, Docker Gateway, E2EE device authorization, and the React browser client. The mobile and Windows visual redesigns remain isolated previews. Displayed preview latency is synthetic.

The original internal package names remain unchanged for compatibility. Start with [README](../README.md), [deployment](DEPLOYMENT.md), [architecture](ARCHITECTURE.md), and [security](SECURITY.md). Public release binaries are not included. The project's own license is pending; upstream licenses remain in place.
