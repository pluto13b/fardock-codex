# 手机 UI 隔离预览

在工作区根目录运行 `pnpm mobile-ui:preview`，打开 `http://127.0.0.1:5182`。电脑上显示手机画幅，`/app.html` 可直接测试响应式页面；`pnpm mobile-ui:build` 输出 `.tmp/mobile-ui-preview`。

使用现有 App、Sidebar、消息组件和内存 CodexServeClient。`mobileMotion` 默认关闭，只有此入口显式开启且 `preview=true` 时生效；专用 CSS 不由正式入口导入。可选模拟回复不进入正式运行。没有连接 Gateway、Companion、app-server 或真实账户。

当前加入整体呼吸感：背景柔光、输入器边缘、可用按钮光晕与面板把手错开周期，文字和点击位置稳定。可见静止时允许少量 CSS 装饰循环；不新增 JavaScript 帧循环。弹窗暂停背后装饰，隐藏/减少动态关闭，禁用按钮保持安静。该决定取代以下早期记录中的静止零动画与纯静态背景。相位截图、布局、点击和减少动态验收记录在 `.tmp/mobile-ui-breath-qa`。

呼吸效果验收：预览构建与 DSH boundary 通过，19 个浏览器检查点、11 张截图；四种画幅、相位间文字/点击区域稳定、发送/停止与减少动态通过。空闲 900 ms 为 4 个 CSS 呼吸动画、0 次应用 rAF 请求；这不包括浏览器合成成本。Headless 页签切换没有产生 hidden 状态，真实后台恢复仍需设备验证。

顶部紧凑状态条显示“模拟”、电脑状态、48 ms 往返延迟示例和加密/只读状态。48 ms 不是实时测量；离线/恢复中为“—”。小状态点仅在在线任务运行时脉动，停止/隐藏/减少动态时停止。检查四种画幅下单行不裁切、运行/停止与离线状态，记录在 `.tmp/mobile-ui-link-qa`。

顶部状态条验收：Web 58/58，预览/正式构建与 DSH boundary 通过；14 个浏览器检查点、6 张截图。普通画幅 28px、短横屏 24px，状态与输入器完整可见。模拟组件位于本目录，共享 App 仅提供可选呈现插槽，正式入口不导入组件或示例 RTT。

本轮体验包括抽屉/底部菜单的可打断进入和退出、任务草稿与阅读位置、跟随最新消息及“回到最新”、多行输入、按下反馈和减少动态。DOM 尺寸/滚动写入按 rAF 合并，目标 60 FPS；透明度和位移由浏览器按刷新节奏播放，不用空转的应用帧循环。草稿和阅读位置在当前页面会话中按任务保存，重载后模拟数据重置。

2026-09-12 视觉方向改为雾白、灰蓝的浅色主题。文字、菜单、侧栏、输入器和设备页同步，背景为静态轻渐变；不改变现有动效与缓冲逻辑。新增目视检查各表面的正文/辅助文字、主操作/禁用态和状态颜色，截图保存在 `.tmp/mobile-ui-light-qa`。

浅色主题验收：构建与 DSH preview boundary 通过，16 个浏览器检查点、16 张截图；四种画幅及模拟发送/停止正常，检查的关键固色色对约 4.75–10.14。报告在 `.tmp/mobile-ui-light-qa/validation.json`，不代表完整无障碍认证或 Android 真机帧率测试。本轮没有修改共享 JavaScript 或正式入口。

验收清单：

- 新回复先缓冲约 600 ms，按字素逐步显现；突发整段、持续小包和短答都能收束到原文。完成后约 900 ms 内收尾，停止立即追上，切任务/历史不重播；减少动态直接显示。用合成文字验证 emoji、组合字符与 Markdown，无真实请求。
- 按钮按下/松开/选中，输入菜单和新建弹窗的进入/退出中间帧与快速反向；退出立即 inert，原焦点和返回键仍有效。检查静止、隐藏和减少动态无多余动画。
- 360 / 393 / 412px 和短横屏：初始视图、输入器、菜单、环境面板完整可见；截图与元素边界共同检查。
- 任务栏搜索、项目切换、两个任务往返：草稿、阅读位置保留，输入能力仍由原快照控制。
- 模型/推理/权限/附件菜单：开→关→重开、快速反向、选中、Esc/返回、焦点归还，关闭节点不接收点击。
- 发送合成文本、可见的逐步回复、停止、单次发送记录；历史阅读不被新内容拉回，点击“回到最新”恢复跟随。
- 减少动态：停用装饰，不影响操作；可见/隐藏后的视图和草稿保持。
- 新建任务、附件增删、审批和问答等既有按钮做聚焦回归，不使用真实任务或凭据。
- 浏览器网络只能访问该 loopback 预览，保存控制台、帧时与截图至 `.tmp/mobile-ui-preview-qa`。结果是桌面浏览器移动模拟，不替代安卓真机帧率、IME 或触感验证。

2026-09-10 验收：Web 50/50、Serve Client 9/9；预览和正式 Web 的 TypeScript、build 与 DSH boundary 通过。63 个浏览器检查点、14 张截图及详细边界保存在 `.tmp/mobile-ui-preview-qa/validation.json`。静止 700 ms 没有应用 rAF 请求或运行动画；菜单场景 2.6 秒未观察到 long task。headless rAF 时序不等于显示帧率，不宣称 Android 稳定 60 FPS。

当前保留的是编译产物预览。重建后可从根目录运行 `pnpm --filter @codex-plus/web exec vite preview --config vite.mobile-preview.config.ts --mode preview --host 127.0.0.1 --port 5182 --strictPort`。该地址只供这台电脑查看手机画幅，没有开启局域网或正式服务。

文字缓冲追加验收：Web 58/58；两种构建与 DSH boundary 通过。30 个浏览器检查点、17 张截图与时序记录位于 `.tmp/mobile-ui-buffer-qa`。合成回复的首次缓冲约 607.7 ms、完成后收尾约 890 ms，静止 900 ms 无应用 rAF 或运行动画；正式延迟与 Android 真机帧率不在本次测量范围。按钮按下/弹窗进出保留中间帧，最终 393px 图补充禁用/可用态；360/393/412px 和 812×375 的弹窗主要控件完整可见。
