# Windows 动效交互预览

双击 `CodexPlusUiPreview.exe` 使用。所有状态均为模拟，关闭窗口只退出预览。

窗口使用开放式布局：左侧两片半透明连接薄片，右侧直接排布状态和操作。没有包裹全部内容的大卡片。

动画默认目标为 **60 FPS**，覆盖背景、玻璃、颜色、呼吸和鼠标响应；减少动态仍可关闭装饰运动。

- **启动服务**：等待时两段锁链持续轻颤、间歇靠近；成功时先蓄力，再快速吸合、回弹，两片玻璃同步扣合，随后一道斜光带动磨砂从上到下退开。
- 窗口、薄片与按钮一起由淡香槟渐变转为灰蓝渐变，连接稳定后停止锁链抖动。
- **空间背景**：宽阔、无描边的雾面空间层与柔光，窗口内移动鼠标可看细微视差；连接时环境亮度轻轻过渡，右侧保持安静。
- **连接手机**：薄片轻轻抬起并靠近，同时从主区域下方抽出占位配对信息，上下细线从中间向两侧展开；再点收起并归位，不生成真实配对码。
- **播放演示**：依次演示启动、连接、展开、断线和恢复，含最后的材质过渡约 10 秒。
- **断线/连接演示**：随时改变模拟状态，取消原演示序列。
- **减少动态**：立即停止装饰动画，功能保持可用。
- 鼠标移入左侧薄片可改变其三维朝向，磨砂会逐渐变得通透，边缘反光随视角移动；移开恢复磨砂。按下按钮可看轻压回弹，右侧正文与操作始终保持平面可读。

源代码只含 WPF 视图、动效与本地模拟器，不包含正式 `AppConfig`、`StartupTask`、`OwnedProcess`，不连接 Gateway、启动 Node/Codex、读取密钥或改动登录任务。

尊重 Windows 的动画偏好；如果底部显示“启用动效”，点击即可体验完整动画。最小化或隐藏会暂停等待循环，快速断线会中断前一组成功效果；动画不阻塞按钮操作。

在仓库根目录运行 `powershell -NoProfile -File scripts/windows-ui-preview.ps1` 构建、检查并打开。加 `-BuildOnly` 只构建和检查。产物与检查截图位于 `.tmp/windows-ui-preview`；运行中的预览需先关闭再重建。

锁链几何沿用项目已有 Lucide 图标，许可见随包 `Lucide-LICENSE.txt`。参考 RhineLabUI 的空间构图与信息揭示，未使用其游戏标志、模型或非代码素材。薄片使用 WPF 自带 Viewport3D、原创简单几何与半透明材质，不包含 Three.js/WebView 或外部模型。

玻璃为本地光学近似：缓存几何法线，用折射取样、菲涅耳反光、预滤波背板和固定微颗粒生成材质，文字/锁链在模糊之后叠加并统一受光。扫描线与逐行粗糙度读取同一显示位置；192×256 材质只在视角、配色、粗糙度或扫描变化时限频更新，静止、隐藏和关闭时停止。仅使用预览自身的合成背板，不采集桌面或其他应用；实现思路与参考来源见 `docs/RHINELAB_UI_EVALUATION.md`。

背景使用三层静态平面、柔光渐变与缓慢位移，共 12 顶点；不重建逐帧几何。背景与脏材质使用 WPF 合成渲染事件，按累积截止时间调度到 60 FPS；隐藏、最小化、减少动态和关闭停止更新。实际呈现帧率仍取决于设备与负载，检查输出中的 WPF 回调率不等于显示器呈现测量。
